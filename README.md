
# Flight Traffic Control Simulator

A web-based simulator that uses a priority queue to schedule
arrivals and departures, with emergency, low-fuel and VIP handling.

## Features
- Arrivals and Departures tables
- Priority queue, runway queue and completed stack
- Add flight form
- Declare emergency dropdown
- Speed slider and control buttons
- System log box

## Priority Colours
- Red: Emergency
- Orange: Low fuel
- Purple: VIP
- Blue: Normal

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository
2. Open `index.html` in a web browser
